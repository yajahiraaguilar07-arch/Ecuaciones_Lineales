# Ecuaciones_Lineales
## Práctica: Método de Gauss - Métodos Numéricos
**Alumna:** Yajahira Aguilar

## Descripción

Este proyecto implementa el Método de Gauss para resolver sistemas de ecuaciones lineales utilizando el lenguaje de programación Java.

El programa permite ingresar una matriz aumentada, aplicar el método de eliminación de Gauss con pivoteo parcial y obtener la solución del sistema de ecuaciones.

## Estructura del proyecto

- `src/EntradaDatos.java` - Se encarga de la lectura de los datos ingresados por el usuario.
- `src/Gauss.java` - Contiene las operaciones necesarias para aplicar el Método de Gauss.
- `src/Main.java` - Contiene la clase principal y ejecuta el programa.

## Lenguaje utilizado

Java
